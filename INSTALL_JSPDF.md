# 📦 Install jsPDF for Invoice Download

## Quick Installation

Run this command in your client directory:

```bash
cd client
npm install jspdf
```

Or if you use yarn:

```bash
cd client
yarn add jspdf
```

## What is jsPDF?

jsPDF is a library for generating PDF documents in JavaScript. We use it to create professional EMI payment invoices.

## After Installation

1. Restart your development server:
   ```bash
   npm run dev
   ```

2. Navigate to `/loans/my-emis`

3. Click any "Invoice" button

4. PDF will download automatically!

## Features Enabled

With jsPDF installed, you can:
- ✅ Download EMI invoices as PDF
- ✅ Professional invoice formatting
- ✅ Automatic file naming
- ✅ Complete payment details
